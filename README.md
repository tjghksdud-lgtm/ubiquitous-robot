# Penny Radar V1

미국 초저가·소형주 실시간 1분봉 탐지 실험용 프로토타입입니다. **자동매매 기능은 없습니다.**

## 실행
1. Python 3.10 이상 설치
2. 폴더에서 `pip install -r requirements.txt`
3. `streamlit run app.py`
4. 브라우저에서 Alpaca Market Data API 키/시크릿을 입력하고 연결

## 주의
- Alpaca 무료 IEX 피드는 미국 전체 시장을 대표하지 않습니다. 전체 시장 SIP 실시간 피드는 적절한 유료 구독이 필요할 수 있습니다.
- API 키는 화면에서 입력하며 코드에 저장하지 않습니다. 서버를 타인에게 공개하지 마세요.
- 연결 후 수집된 봉만 분석합니다. 과거 이력, 종목 상장시장 필터, 전일 종가 대비 변동률, 정규 세션별 집계, 실제 RVOL, SEC 공시/희석 필터, 백테스트, 알림, 재연결 기능은 아직 구현되지 않았습니다.
- 단순 점수는 수익 확률이 아니며 매매에 사용하기 전에 검증이 필요합니다.
